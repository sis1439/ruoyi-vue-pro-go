# blockers.md — 阻塞项与需要人工提供的输入

## 1. 外部阻塞（缺少凭证/环境，工程侧无法推进）

| 编号 | 阻塞项 | 影响的用例 | 需要人工提供 |
|---|---|---|---|
| BLK-01 | 无微信商户资料 | A16、A17、A22、A23 的真实联调 | 商户号、AppID、API v3 密钥、商户私钥与证书序列号、微信支付公钥及 ID、已备案的回调域名，以及**书面授权**后由获授权人员执行小额支付/退款 |
| BLK-02 | 本机无 PostgreSQL | A01～A03、A06～A14、A19～A23 的数据库断言 | 目标 PostgreSQL 的**具体版本号**（任务书明确不认可"PostgreSQL 15"这个前序示例），以及测试库连接方式 |
| BLK-03 | 本机无 Redis | A20、A21、A25 | 测试 Redis 地址与库号；商城使用的键名前缀（须与既有业务隔离） |
| BLK-04 | 无对象存储凭证 | T11 的商品图片上传/展示/删除 | 对象存储类型、Bucket、访问凭证、允许的类型与大小上限 |
| BLK-05 | 无短信/物流渠道凭证 | T11 的短信登录、物流查询 | 是否首期启用；启用则提供渠道凭证，不启用则确认从前后端同时关闭 |
