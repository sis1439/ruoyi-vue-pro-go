| R1 支付成功与通知任务不原子 | 支付/退款/转账本地状态及通知任务使用同一事务；插入失败返回错误；退款累计金额加入同事务，投递状态与日志也同事务 | PostgreSQL 故障注入验证回滚、事务连接一致、成功后重复回调只产生一条任务 |
